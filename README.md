# Smart Irrigation Scheduling using Q-Learning

A Reinforcement Learning mini-project that learns an irrigation policy for maintaining
healthy soil moisture while reducing unnecessary water usage.

## Main Algorithm
**Q-Learning**

## Supporting Technique
**Epsilon-Greedy action selection with epsilon decay**

## Baselines
- Random policy
- Rule-based irrigation policy

## Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Streamlit

## How to Run

### 1. Create/activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the dashboard

```bash
streamlit run app.py
```

## Demonstration Flow

1. Open **Overview** and explain the RL formulation.
2. Go to **Train Agent**.
3. Use the default parameters first.
4. Show Reward vs Episode.
5. Show Success Rate and Epsilon Decay.
6. Open **Live Simulation** and explain the learned decisions.
7. Open **Comparison** and compare Q-Learning with Random and Rule-Based policies.
8. Open **Q-Table** and explain the learned action for each state.

## Suggested Default Parameters

- Learning rate α = 0.10
- Discount factor γ = 0.90
- Initial ε = 1.00
- Epsilon decay = 0.995
- Minimum ε = 0.05
- Episodes = 1500
- Episode length = 24 steps

## Important Academic Note

The simulator is intentionally small and interpretable. It is a demonstration of
Reinforcement Learning methodology rather than a production agricultural control system.
Results should be generated by running the application, not manually fabricated.
